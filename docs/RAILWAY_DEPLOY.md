# Eski Railway yo‘riqnomasi

Bu hujjat **tarixiy**; Railway’da yangi deploy boshlash uchun ishlatmang. Joriy repository deploy oqimi va production ishga tushirish holati `docs/DEPLOY.md` da qayd etilgan.

Backend muhit o‘zgaruvchilarini qayerdan olish va server-side sozlash bo‘yicha `docs/VERCEL_DEPLOY.md` ga qarang. Hozirgi repository Vercel frontend va alohida backend serverdan foydalanadi; backend’ni Vercel Container Runtime’ga ko‘chirish alohida konfiguratsiya, billing tekshiruvi va live sinovni talab qiladi, buni bajarilgan deb hisoblamang.
